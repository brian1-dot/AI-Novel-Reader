# US Citizenship AI · 美国入籍学习
独立安装的安卓应用，包名 `com.brian.citizenship`。与小说听书应用源码和安装包互不干扰。

## 数据
- USCIS 2025 公民知识128道官方题及全部官方可接受答案（下载原始政府 PDF，在云端生成离线 JSON）
- 中文参考：USAHello 2025 简体翻译（非 USCIS 官方中文翻译）
- USCIS 阅读/写作词汇；根据词汇编制非官方阅读听写训练句
- 动态官员答案需要面试时复核，佛州州长/参议员可能因选举变化
- 本产品不是 USCIS 官方软件

## 构建
运行 `Build Citizenship APK` 工作流，从 Artifacts 下载 `US-Citizenship-AI-APK`，解压并安装APK。
